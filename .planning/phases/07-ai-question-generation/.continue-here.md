## BLOCKING CONSTRAINTS — Read Before Anything Else

> There are no unresolved failures in Phase 7 itself. The following are runtime
> pitfalls discovered *this session* (during Phase 7 E2E) that a resuming agent
> MUST remember when building/testing future phases against the live stack.

- [ ] CONSTRAINT: E2E helper servers must run in a **detached Docker container**, not as `&`-backgrounded shell jobs. The persistent bash session hangs/times out on `nohup ... &` background jobs (the shell waits on the child's open fds). Run the mock AI/LLM provider as `docker run -d --name mock-llm -p <port>:<port> -v /path:/mock.py python:3-alpine python /mock.py`. Structural mitigation: always containerize long-running mock servers.
- [ ] CONSTRAINT: Academic scope routes live under `/api/v1/academic/*` (e.g. `POST /academic/subjects`, `/academic/subjects/:subjectId/chapters`, `/academic/chapters/:chapterId/topics`) — NOT `/api/v1/subjects`. Verify the actual RouterExplorer `Mapped {...}` routes from `docker logs` before writing E2E scripts.
- [ ] CONSTRAINT: E2E against the fixed institute UUID (`11111111-...`) accumulates academic rows, so reusing static slugs (`physics`, `mechanics`, `newton-laws`) collides on re-runs. Make slugs unique per run (e.g. `"slug":"physics$(date +%s)"`).

## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| str.format on a string containing JSON braces | Prompts built with `_SYSTEM_TEMPLATE.format(...)` fail with `KeyError: '"questions"'` / `ValueError: Single '}' encountered` when the template also contains literal JSON `{`/`}` | blocking | Escape literal braces as `{{`/`}}` in `.format()` templates; keep variable placeholders (`{type_}`) unescaped. Simpler: use a plain non-f string for the schema + f-string/concatenation for the dynamic lines |
| Backgrounded shell servers stall the tool | `nohup ... &` in the persistent shell hangs/timeouts out | blocking | Run long-lived servers (mock AI/LLM/OCR) as detached Docker containers, not shell background jobs |
| Stale/duplicate E2E fixtures | Re-running against the same institute UUID hits unique-slug 409s and stale memberships | advisory | Unique per-run slugs; DELETE-and-reinsert memberships with unique ids |
| Field-route drift | Route prefixes drift from docs (academic under `/academic/`) | advisory | Read the live RouterExplorer `Mapped` logs before scripting |

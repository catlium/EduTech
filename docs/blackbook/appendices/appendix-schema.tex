\chapter{DATABASE SCHEMA INVENTORY}
\thispagestyle{empty}

This appendix inventories the thirty-three tables of the PostgreSQL schema,
grouped by domain.

\clearpage

The schema contains 33 tables grouped by domain. The full entity--relationship
diagram is shown in Figure~\ref{fig:erd}.

\midrule
\endhead

Entity names use lowercase with underscores. All domain tables are
tenant-scoped by an institute reference or through their parent chain, and
scope chains (topic $\rightarrow$ chapter $\rightarrow$ subject) are enforced
by database check constraints.
